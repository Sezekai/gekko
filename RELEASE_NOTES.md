Gekko 1.2.0: a reworked Tidy up, a duplicate finder, and lists that remember themselves.

Tidy up
- Leaves more alone: songs already in an album folder aren't moved (Move: "Only songs not already in an album folder", or every song, or none), file names that start with a track number keep it, and names that only differ in punctuation (like ") aren't renamed.
- Click a song to open a panel beside the list with its current and new name, its folder and where it goes, every tag (now and new), and the cover. Change any of it: another name or keep the current one, type your own, another folder or don't move it, other tag values, leave tags out, cover or no cover. "Apply to this song" does just that one. Your changes are kept until applied.
- New name and Moves to can be edited right in the list (double-click).
- Filters you can mix: Renamed, Moved, Tags, Cover art, Changed by you, each any / yes / no. They choose what's listed and what Apply does, separately from the Do ticks.
- Ticked songs are clearer (accent tick boxes); left-out songs are faint and struck through.
- The same file name is allowed in different folders; within a folder nothing is ever overwritten.

Duplicates (a new tab in Tidy up)
- Same file name (ignoring track numbers, "(2)" and "- Copy"), same title and artist, or same sound (audio fingerprints, kept for next time, with progress in the title bar).
- Each group marks the copy to keep; recycle the rest in one go, or choose.

Lists
- Alternating row shades and faint column lines everywhere.
- Resize and move columns in every list; widths, order and sort are remembered per list.
- Tile sizes per section, the Now playing panel width and other panel widths are remembered.

Replace the App folder in E:\Pictures\Gekko with the one in Gekko.zip.
