Gekko 1.2.3: sorting everywhere, a bolder logo, and a start-up error fixed.

- Fixed "TypeError: 'str' object does not support item assignment" at start: two lists' saved column layouts had names that clashed in the settings file. Each list now saves under its own name, and the settings file copes with such clashes.
- Sort songs anywhere (Songs, a genre, a folder, an artist, a playlist): by title, artist, album, genre, date released, date added, last played, length, rating, plays, favourites, track number, file name, folder or quality. A button next to it turns it the other way round, named for each field (A to Z / Z to A, Newest first / Oldest first, Most first / Fewest first…). It works in the grid view too, matches the column headers, and is remembered per screen. "As listed" goes back to a playlist's own order.
- Albums, Artists and Genres sort both ways too.
- The column lines in lists now run the full height of each row, so they join up.
- The logo's note is solid and thicker, and centred; the app icon (taskbar, Gekko.exe) uses the same note.

Replace the App folder in E:\Pictures\Gekko with the one in Gekko.zip.
